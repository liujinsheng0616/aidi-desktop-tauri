# AI 场景精简 AI 审核字段：移除 aiClassification / aiCapabilityLevel / finalAiCapabilityLevel

## Context

AI 场景的审核只需要：**评级（A/B/C/不予收录/无法判断）+ AI 评级理由**，通过 AI 评级后计算积分。当前 AIScene 模型从 AIProject 复制了 `aiClassification`（项目/场景判定）和 `aiCapabilityLevel`（L1-L5 智能体能力等级），以及人工终审的 `finalAiCapabilityLevel`——这些字段对场景不适用，需要移除。

**保留的字段**（不变）：`aiDecision`, `aiLevel`, `aiReasoning`, `aiEvidence`, `aiBlockers`, `aiSuggestions`, `aiConfidence`, `aiReviewedAt`, `aiAutoReview`(JSON备份)

## 修改清单

### 1. Prisma Schema — `prisma/schema.prisma` (AIScene 模型, ~line 483-502)

删除 3 个字段：
- `aiClassification   ProjectClassification?`
- `aiCapabilityLevel  AgentBeltLevel?`
- `finalAiCapabilityLevel AgentBeltLevel?`

### 2. 数据库迁移 — `prisma/migrations/<timestamp>_remove_scene_ai_fields/migration.sql`

```sql
ALTER TABLE `AIScene` DROP COLUMN `aiClassification`;
ALTER TABLE `AIScene` DROP COLUMN `aiCapabilityLevel`;
ALTER TABLE `AIScene` DROP COLUMN `finalAiCapabilityLevel`;
```

### 3. API POST 路由 — `src/app/api/ai-scene/route.ts` (~line 145-148, 215-216)

- 删除 `aiCapabilityLevel` 和 `aiClassification` 的变量提取
- 删除 prisma.create data 中的 `aiClassification` 和 `aiCapabilityLevel` 赋值

### 4. API PUT 路由 — `src/app/api/ai-scene/[id]/route.ts` (~line 174-177, 237-238)

- 同 POST，删除变量提取和 prisma.update data 赋值

### 5. 用户端详情页 — `src/app/incentive/scene/detail/[id]/page.tsx`

- 从 `SceneDetail` interface 删除 `aiClassification` 和 `aiCapabilityLevel`、`finalAiCapabilityLevel`
- 从 AI 审核信息模块删除 "AI 项目/场景判定" 和 "AI 智能体能力等级" 两行
- 从人工复核信息模块删除 "人工复核智能体能力等级" 一行
- 删除 `CLASSIFICATION_LABEL` 常量（如不再被其他行引用）
- 删除 `BELT_LABEL` 常量（如不再被其他行引用）

### 6. 管理端详情页 — `src/app/admin/ai-scene/[id]/page.tsx`

- 同用户端，删除 interface 字段、显示行、常量

### 7. 种子文件 — `prisma/seed-three-modules.ts`

- `buildReview` 函数可保留完整结构（aiAutoReview JSON 备份不强制删除）
- 确认 seed 不直接写入 `aiClassification`/`aiCapabilityLevel`/`finalAiCapabilityLevel` 独立列（当前确认不写入）

### 8. AI Agent 类型 — `src/lib/ai/agent/types.ts` & `src/lib/ai/agent/prompts.ts`

**不修改**。`AuditDecisionResult` 接口仍包含 `classification` 和 `aiCapabilityLevel`，因为 AIProject 仍需要。AI 仍会生成这些字段写入 `aiAutoReview` JSON 备份，只是不再提取到 AIScene 独立列。

## 不修改的内容

- `aiDecision`、`aiLevel`、`aiReasoning`、`aiEvidence`、`aiBlockers`、`aiSuggestions`、`aiConfidence`、`aiReviewedAt` — 全部保留
- `aiAutoReview` JSON 列 — 保留（AI 评审完整快照备份）
- AIProject 模型的对应字段 — 不动
- AI Agent 类型和 prompt — 不动（AIProject 仍需要）

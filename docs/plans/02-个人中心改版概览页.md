# 个人中心改版：概览卡片式聚合页

## Context

当前 `/incentive/my` 个人中心只展示**奖项申报**列表，用户看不到自己的 AI 项目、AI 场景、人才认证记录。三个模块各有独立的 "我的" 页（`project/my`、`scene/my`、`certification/my`），但彼此互不打通，用户没有统一入口。

改版目标：在 `/incentive/my` 页面顶部增加**概览统计卡片区域**，展示四个板块的条目数，点击卡片跳转到对应的独立列表页。下方的奖项申报列表保持不变。

## 改动方案

### 只改一个文件：`src/app/incentive/my/page.tsx`

在现有页面的标题行和筛选器之间，插入一个统计卡片行（4 张卡片并排），点击跳转：

| 卡片 | 数据来源 API |转目标 |
|------|-------------|---------|
| 我的申报 | 已有 `/api/applications`（复用现有数据，不需额外请求） | 留在当前页 |
| 我的项目 | `/api/ai-project` | `/incentive/project/my` |
| 我的场景 | `/api/ai-scene` | `/incentive/scene/my` |
| 我的认证 | `/api/yellow-belt` + `/api/green-belt` + `/api/black-belt`（三个并行请求，合计总数） | `/incentive/certification/my` |

### 实现细节

1. **并行加载数据**：页面挂载时，除了已有的 `fetch("/api/applications")`，并行发起项目/场景/认证的计数请求。由于这些 API 返回的是数组，直接取 `.length` 即可（数据量不大，不需要新建 count 接口）。

2. **卡片 UI**：4 张卡片横排（flex），每张包含图标 + 标题 + 数字。样式与现有 `surface-card` 一致，hover 时有微妙阴影变化，cursor: pointer。

3. **加载态**：数字位置显示 Spin（小尺寸），加载完毕后显示数字。

4. **申报计数复用**：我的申报卡片直接用已有的 `data.length`，不需要额外请求。

5. **下方内容不变**：奖项申报的筛选器 + 卡片列表 + 新建/删除/撤回逻辑全部保持原样。

## 验证方式

1. 访问 `http://localhost:3055/incentive/my`
2. 确认顶部显示 4 张统计卡片，数字正确
3. 点击"我的项目"卡片 → 跳转到 `/incentive/project/my`
4. 点击"我的场景"卡片 → 跳转到 `/incentive/scene/my`
5. 点击"我的认证"卡片 → 跳转到 `/incentive/certification/my`
6. 点击"我的申报"卡片 → 留在当前页
7. 下方申报列表功能不受影响（筛选、新建、编辑、撤回、删除）
8. TypeScript 编译通过

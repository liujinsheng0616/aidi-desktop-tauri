# AIProject 模型字段标准化重构计划

## Context

当前 AIProject 模型结构问题：
1. **核心业务字段寄生在 formData JSON 中** — `manDaysPerMonthSaved`、`affectedEmployees`、`contributionCoefficient`、`aiInvestmentCost`、`priority`、`mainImplementer`、`projectPlan`、`currentProgress`、`valueProof` 等字段仅存在 formData JSON 中，无独立数据库列
2. **AI 审核结果寄生在 aiAutoReview JSON 中** — `decision`、`level`、`classification`、`aiCapabilityLevel`、`reasoning`、`evidence`、`blockers`、`suggestions`、`confidence` 全部塞在 JSON 里
3. **coverageScope / coverageRank 三处冗余** — 独立列 `coverageScope`(string) + `valueComputation.coverageRank`(number) + `formData.coverageRank`(string)，类型混乱
4. **前后端必填不一致** — 表单 required 但数据库可空，或反之
5. **valueComputation JSON 混杂计算结果和人工填写值** — `actualValue`、`points` 是人工复核填写的，却寄生在计算结果 JSON 中
6. **User-AIProject 关联** — 已有 `applicantId` 外键 + `applicant` relation，关联已完整，无需修改

## 改动范围

### 1. Prisma Schema 重构 — `prisma/schema.prisma`

**新增枚举**：
```prisma
enum ProjectClassification {
  PROJECT
  SCENE
  NON_AI
}
```

**不新增枚举的字段**（保持表单 option value 原样存储）：
- `priority` → `String?`（表单 select value 是 "P0"/"P1"/"P2"/"P3" 字符串）
- `mainImplementer` → `String?`（表单 select value 是中文字符串）
- `contributionCoefficient` → `Float?`（表单 radio value 是 "0.3" 等字符串，parseFloat 转为 number）
- `coverageRank` → `Int`（表单 radio value 是 "1"/"2"/"3"，num() 转为 number）
- `depthRank` → `Int`（同上）

**新版 AIProject 模型**（按三层分组：用户填报 / AI 自动审核 / 人工终审）：

```prisma
model AIProject {
  id                String            @id @default(cuid())
  applicantId       String
  applicant         User              @relation("AIProjectApplicant", fields: [applicantId], references: [id])

  // === 用户申报字段 ===
  projectName       String            // 必填
  projectType       AIProjectType     // 必填
  projectStatus     AIProjectStatus   // 必填
  goLiveDate        DateTime?         // 选填
  description       String            @db.Text  // 必填
  orgUnit           String            // 必填
  domain            String            // 必填
  kpiDescription    String            @db.Text  // 必填
  businessPM        String            // 必填（姓名拼接）
  businessPMUserId  String?           // 选填（ID 逗号拼接）
  aiPM              String            // 必填（姓名）
  aiPMUserId        String?           // 选填（ID）

  // 基础信息 — 从 formData 提升为独立列
  priority          String?           // 选填
  mainImplementer   String?           // 选填
  projectPlan       String?           @db.Text  // 选填
  currentProgress   String?           @db.Text  // 选填

  // 价值核算字段 — 从 formData 提升为独立列
  jobType                  JobType?          // 选填
  manDaysPerMonthSaved     Int?             // 选填（人天/月）
  affectedEmployees        Int?             // 选填（人）
  contributionCoefficient  Float?           // 选填（0.3/0.5/0.8/1.0）
  aiInvestmentCost         Float?           // 选填（万元/年）
  coverageRank             Int              // 必填（1/2/3）— 替代旧 coverageScope
  depthRank                Int              // 必填（1/2/3）
  systemsIntegrated        Int?             // 选填
  valueProofFiles          Json?            // 选填（文件数组，保持 JSON）
  valueProofLink           String?          @db.Text  // 选填（链接）

  // ===计算字段 ===
  annualValue              Float?           // 年化净值（万元/年）
  firstYearValue           Float?           // 首年价值（万元）
  valueBreakdown           String?          @db.Text  // 核算口径
  computedLevel            AIProjectLevel?  // 公式基准定级

  // === AI 自动审核字段 — 从 aiAutoReview JSON 提升为独立列 ===
  aiDecision               AuditDecisionType?      // PASS/REJECT/NEED_INFO
  aiLevel                  AIProjectLevel?         // AI 评定等级
  aiClassification         ProjectClassification?   // PROJECT/SCENE/NON_AI
  aiCapabilityLevel        AgentBeltLevel?          // L1-L5/NON_AGENT
  aiReasoning              Json?                    // AI 评定依据数组
  aiEvidence               Json?                    // 证据清单
  aiBlockers               Json?                    // 阻断项数组
  aiSuggestions            Json?                    // 建议数组
  aiConfidence             Float?                   // 置信度 0-1
  aiReviewedAt             DateTime?

  // === 人工终审字段 ===
  humanReviewStage         AuditDecisionType?      // 人工复核结论
  reviewerId               String?                 // 审核人 ID
  reviewerComment          String?                 @db.Text  // 审核备注
  reviewedAt               DateTime?
  reviewerClassification   ProjectClassification?  // 人工复核分类
  reviewerClassifyReason   String?                 @db.Text  // 分类理由
  finalAiCapabilityLevel   AgentBeltLevel?         // 人工能力等级
  finalAiCapabilityReason  String?                 @db.Text  // 能力等级原因
  finalLevel               AIProjectLevel?         // 最终评级
  finalGradeReason         String?                 @db.Text  // 评级理由
  actualValue              Float?                  // 实际价值产出 — 从 valueComputation 提升
  points                   Float?                  // 价值转化积分 — 从 valueComputation 提升

  // === 时间戳 ===
  submittedAt              DateTime?
  createdAt                DateTime            @default(now())
  updatedAt                DateTime            @updatedAt

  // === 保留的 JSON 列（仅非结构化附属数据）===
  formData                 Json?                // 仅保留申请人只读字段快照
  aiAutoReview             Json?                // 保留原始 AI JSON 快照（供 AuditReportCard 完整渲染）

  talentRefs              TalentProjectRef[]
}
```

**删除旧列**：`coverageScope`（被 `coverageRank` 替代）、`valueComputation`（拆解为独立列）

**删除不用的枚举**：`ContributionCoefficient`（未使用）

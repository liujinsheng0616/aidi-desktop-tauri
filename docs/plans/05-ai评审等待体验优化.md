# 优化 AI 评审等待体验

## Context

用户反馈 AI场景、AI项目、黄带、绿带的 AI 评审过程"很费时间"。当前流程：用户点"提交并 AI 评审" → 弹 Modal → 只显示 `Spin + "AI 评审专家正在审阅…"` → 等待 30-120 秒（DeepSeek 推理模型 + 大 prompt）→ 结果一次性出现。

问题：等待期间只有一行文字 + 旋转图标，没有预计时间、没有进度阶段提示、没有计时器，用户不知道要等多久、也不知道是否在正常工作，体验焦虑。

**用户选择的方向：优化等待体验**（不改变 AI 调用速度，改善等待期间 UX）。

## 现状分析

- `_META` 完全相同（PASS/REJECT/NEED_INFO → label/color/icon）

- thinking 区域：maxHeight 200，`whitespace-pre-wrap`，光标 `animate-pulse`

| 确认按钮文案 | `确认提交` | `确认提交（进入人工复核）` | `确认提交（进入人工复核）` |

| 兜底文案 | `可直接提交场景，等待管理员人工复核` | `您可以直接提交项目，后续由人工复核` | `可直接提交，等待管理员人工复核` |
| 底部申诉提示 | 有（PASS/REJECT/NEED_INFO 三种文案） | 无 | 无 |
| confidence 类型 | `number` | `number \| null` | `number` |

### 后端 SSE 流（不改动）

- [audit-decision/route.ts#L170-L243](src/ai/audit-decision/route.ts#L170-L243) — SSE 流，发送 `thinking` chunk → `result` → `[DONE]`
- [agent/index.ts#L74-L140](src/lib/ai/agent/index.ts#L74-L140) — `executeAgentStream`，120s 超时，1 次重试
- 模型：`deepseek-v4-pro`（推理模型，会先输出 `reasoning_content` 再输出 `content`）

## 方案

### 核心思路

在 3 个页面的 AI 评审 Modal 中，**reviewing 状态下**增加：
1. **预计耗时提示** — "预计 30-60 秒"
2. **阶段进度文案** — 用计时器驱动阶段性文案，让用户感知进度
3. **已** — 显示"已等待 X 秒"
4. **thinking 空状态提示** — thinking 为空时显示"正在连接 AI 评审服务…"，收到首个 token 后自动切换为流式文本

由于 3 个页面的 Modal 结构高度相似，提取一个共享组件 `<AIReviewModal>`，通过 props 处理差异。每个页面删除约 40-50 行 Modal JSX，替换为一个组件调用。

### 新建共享组件

文件：`src/components/incentive/AIReviewModal.tsx`

```tsx
import { useEffect, useState } from "react";
import { Button, Modal, Spin, Tag } from "@arco-design/web-react";
import {
  IconCheckCircleFill,
  IconCloseCircleFill,
  IconExclamationCircleFill,
} from "@arco-design/web-react/icon";

// 各页面 AuditResult 字段不同，取并集，不渲染的字段设为可选
interface AuditResult {
  decision: "PASS" | "REJECT" | "NEED_INFO";
  level: string | null;
  reasoning: string[];
  blockers: string[];
  confidence?: number | null; // 项目页面可为 null
  // 以下字段各页面定义不同但不在此 Modal 渲染，设为可选不影响
  classification?: string | null;
  aiCapabilityLevel?: string | null;
  evidence?: { criterion: string; status: string; note: string }[];
  suggestions?: string[];
}

const DECISION_META: Record<string, { label: string; color: string; icon: React.ReactNode }> = {
  PASS: { label: "建议通过", color: "#00B42A", icon: <IconCheckCircleFill /> },
  REJECT: { label: "建议驳回", color: "#F53F3F", icon: <IconCloseCircleFill /> },
  NEED_INFO: { label: "需补充材料", color: "#FF7D00", icon: <IconExclamationCircleFill /> },
};

interface AIReviewModalProps {
  open: boolean;
  reviewing: boolean;
  submitting: boolean;
  thinking: string;
  audit: AuditResult | null;
  aiError: boolean;
  levelLabel?: Record<string, string>;
  // 确认按钮文案（场景："确认提交"，项目/认证："确认提交（进入人工复核）"）
  confirmLabel?: string;
  // 底部提示文案（仅场景页传，依赖 audit.decision）
  bottomHint?: string | null;
  // 兜底区域文案（场景："可直接提交场景，…"，项目："您可以直接提交项目，…"，认证："可直接提交，…"）
  fallbackText?: string;
  // 直提按钮文案（场景/认证："直接提交"，项目："直接提交（进入人工复核）"）
  directSubmitLabel?: string;
  // 按钮回调
  onCancel: () => void;
  onConfirmSubmit: () => void;
  // AI项目用 handleDirectSubmit，场景/认证不传 → fallback 到 onConfirmSubmit
  onDirectSubmit?: () => void;
}

export function AIReviewModal({
  open, reviewing, submitting, thinking, audit, aiError,
  levelLabel, confirmLabel = "确认提交（进入人工复核）",
  bottomHint, fallbackText = "AI 评审服务暂时不可用，可直接提交，等待管理员人工复核。",
  directSubmitLabel = "直接提交",
  onCancel, onConfirmSubmit, onDirectSubmit,
}: AIReviewModalProps) {
  const [elapsed, set = useState(0);

  // reviewing 开始时计时，结束/卸载时清除
  useEffect(() => {
    if (!reviewing) { setElapsed(0); return; }
    const timer = setInterval(() => setElapsed((e) => e + 1), 1000);
    return () => clearInterval(timer);
  }, [reviewing]);

  // 阶段文案
  const stageText = (() => {
    if (!reviewing) return null;
    if (elapsed < 5 && !thinking) return "正在连接 AI 评审服务…";
    if (elapsed < 15 || !thinking) return "AI 评审专家正在审阅…";
    if (elapsed < 30) return "正在逐条核对申报材料…";
    if (elapsed < 60) return "正在生成评审结论…";
    return "评审较慢，仍在处理中，请稍候…";
  })();

  const meta = audit ? DECISION_META[audit.decision] : null;

  return (
    <Modal title="AI 评审" visible={open} footer={null}
      onCancel={() => !reviewing && !submitting && onCancel()}
      maskClosable={!reviewing && !submitting} style={{ width: 560 }}>

      {/* reviewing 状态：进度提示 + 计时 + thinking 流 */}
      {reviewing && (
        <>
          <div className="flex items-center justify-between text-sm mb-1">
            <span style={{ color: "var(--color-accent)" }}>
              <Spin size={14} /> {stageText}
            </span>
            <span className="text-xs" style={{ color: "var(--color-text-tertiary)" }}>
              预计 30-60 秒 · 已等待 {elapsed}s
            </span>
          </div>
          <div className="mb-3 px-3 py-2 rounded-lg text-xs leading-relaxed whitespace-pre-wrap"
            style={{ background: "var(--color-fill-1, #f7f)", color: "var(--color-text-secondary)",
              maxHeight: 200, overflow: "auto" }}>
            {thinking || "等待 AI 输出…"}
            {reviewing && <span className="animate-pulse">|</span>}
          </div>
        </>
      )}

      {/* 结果区 */}
      {audit && meta && (
        <div className="space-y-3">
          <div className="flex items-center gap-2">
            <span style={{ color: meta.color, fontSize: 18 }}>{meta.icon}</span>
            <span className="font-semibold" style={{ color: meta.color }}>{meta.label}</span>
            {audit.level && levelLabel && (
              <Tag color="arcoblue">{levelLabel[audit.level] || audit.level}</Tag>
            )}
            {audit.confidence != null && audit.confidence > 0 && (
              <span className="text-xs" style={{ color: "var(--color-text-tertiary)" }}>
                置信度 {Math.round(audit.confidence * 100)}%
              </span>
            )}
          </div>
          {audit.reasoning.length > 0 && (
            <div>
              <div className="text-xs font-medium mb-1" style={{ color: "var(--color-text-secondary)" }}>评审依据</div>
              <ul className="text-xs space-y-1" style={{ color: "var(--color-text-secondary)", paddingLeft: 16 }}>
                {audit.reasoning.map((r, i) => <li key={i}>{r}</li>)}
              </ul>
            </div>
          )}
          {audit.blockers.length > 0 && (
            <div>
              <div className="text-xs font-medium mb-1" style={{ color: "#F53F3F" }}>关键问题</div>
              <ul className="text-xs space-y-1" style={{ color: "#F53F3F", paddingLeft: 16 }}>
                {audit.blockers.map((b, i) => <li key={i}>{b}</li>)}
              </ul>
            </div>
          )}
          <div className="flex justify-end gap-2 pt-2">
            <Button onClick={onCancel}>返回修改</Button>
            <Button type="primary" loading={submitting} disabled={submitting}
              onClick={onConfirmSubmit}
              style={{ background: "var(--gradient-tech)", borderRadius: 100 }}>
              {confirmLabel}
            </Button>
          </div>
          {bottomHint && (
            <div className="text-[11px]" style={{ color: "var(--color-text-tertiary)" }}>{bottomHint}</div>
          )}
        </div>
      )}

      {/* 兜底：AI 评审不可用 */}
      {!reviewing && !audit && aiError && (
        <div className="space-y-3">
          <div className="text-sm" style={{ color: "var(--color-text-secondary)" }}>
            {fallbackText}
          </div>
          <div className="flex justify-end gap-2 pt-2">
            <Button onClick={onCancel}>返回修改</Button>
            <Button type="primary" loading={submitting} disabled={submitting}
              onClick={onDirectSubmit ?? onConfirmSubmit}
              style={{ background: "var(--gradient-tech)", borderRadius: 100 }}>
              {directSubmitLabel}
            </Button>
          </div>
        </div>
      )}
    </Modal>
  );
}
```

## 关键风险与防 bug

| # | 风险 | 处理方式 |
|---|---|---|
| 1 | **确认按钮文案不统一** | 场景"确认提交" vs 项目/认证"确认提交（进入人工复核）"→ 通过 `confirmLabel` prop 处理 |
| 2 | **兜底文案不同** | 场景"可直接提交场景" vs 项目"您可以直接提交项目" vs 认证"可直接提交" → 通过 `fallbackText` prop 处理 |
| 3 | **直提按钮文案不同** | 场景/认证"直接提交" vs 项目"直接提交（进入人工复核）" → 通过 `directSubmitLabel` prop 处理 |
| 4 | **直提按钮 handler 不同** | 项目用 `handleDirectSubmit`，场景/认证用 `handleConfirmSubmit` → 组件用 `onDirectSubmit ?? onConfirmSubmit` fallback |
| 5 | **confidence 可 null** | 项目页面 `confidence: number \| null` → 组件判断 `audit.confidence != null && audit.confidence > 0` |
| 6 | **AuditResult interface 差异** | 项目有 `classification`/`aiCapabilityLevel`，场景有 `evidence`/`suggestions`，但这些字段在 Modal 中**不渲染** → 组件 interface 中设为可选 |
| 7 | **thinking 区初始空状态** | DeepSeek 推理模型前几秒可能不输出 token → 组件显示"等待 AI 输出…"占位 |
| 8 | **计时器内存泄漏** | `useEffect` 清理 `clearInterval`，`reviewing` 变 false 时重置 `elapsed` |
| 9 | **Modal 关闭逻辑** | `onCancel` `!reviewing && !submitting` 保持不变 |
| 10 | **bottomHint 依赖 audit** | 场景页 `bottomHint` 依赖 `audit.decision`，在父组件计算后传字符串，组件内不再访问 audit |
| 11 | **图标 import 冗余** | 3 个页面原有 `IconCheckCircleFill` 等 import 可删除（移到组件内），但需保留页面中其他地方用到的图标 |

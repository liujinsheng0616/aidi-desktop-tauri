# AIDI Desktop 悬浮球使用说明书

> 本文档面向首次使用 AIDI Desktop 的用户，详细介绍悬浮球及所有配套功能的操作方法。

---

## 一、什么是 AIDI Desktop

AIDI Desktop 是一款桌面智能助手工具，以一个小型悬浮球的形式常驻在您的电脑屏幕边缘。您可以通过它快速提问、截图提问、查询 IT 运维流程、切换 AI 模型、优化系统等，无需打开浏览器或切换应用。

**核心特点：**
- 始终悬浮在桌面最上层，随叫随到
- 支持文字提问和截图提问
- 内置 17 个 IT 运维场景，自动识别并给出流程指引和 OA 链接
- 支持通义千问和 DeepSeek 两种 AI 模型自由切换
- 可自定义外观（颜色、透明度、大小）

## 二、安装与登录

### 2.1 安装

1. 从公司内部渠道获取 AIDI Desktop 安装包（`.dmg` ��� macOS，`.exe` 为 Windows）
2. macOS：双击 `.dmg` 文件，将 AIDI Desktop 拖入"应用程序"文件夹
3. Windows：双击 `.exe` 文件，按提示完成安装

### 2.2 首次启动与登录

1. 双击应用图标启动
2. 首次启动会弹出登录窗口，显示飞书扫码登录二维码
3. 用手机飞书 App 扫描二维码完成登录
4. 登录成功后，悬浮球自动出现在屏幕边缘

> **提示：** 登录信息会保存在本地，下次启动无需重新登录。如果长时间不使用或更换电脑，需要重新登录。

### 2.3 系统托盘图标

启动后，系统托盘（macOS 在屏幕顶部菜单栏，Windows 在右下角任务栏）会出现 AIDI 图标。

**已登录时右键菜单：**
- 显示浮动球 / 隐藏浮动球：切换悬浮球可见性
- 退出：完全退出应用

**未登录时右键菜单：**
- 登录：打开登录窗口
- 退出：完全退出应用

## 三、悬浮球基本操作

### 3.1 悬浮球长什么样

悬浮球是一个圆形球体，上面显示"AIDI"文字和一条下划线装饰。旁边有一个搜索图标按钮（放大镜形状）。整体呈胶囊形状，球在左侧，搜索按钮在右侧。

### 3.2 鼠标悬停（显示菜单）

将鼠标移动到悬浮球上，停留约 0.5 秒后，会自动弹出菜单窗口。菜单包含四个选项：

| 菜单项 | 说明 |
|--------|------|
| 界面外观 | 设置主题模式、透明度、颜色主题 |
| 模型选择 | 切换 AI 模型（通义千问 / DeepSeek） |
| 系统优化 | 打开系统优化工具窗口 |
| 关于 | 查看版本号、检查更新、下载安装新版本 |

将鼠标移开悬浮球后，菜单和悬浮球会自动隐藏到屏幕边缘。

### 3.3 左键点击

- **单击悬浮球：** 如果输入框已展开，点击球会收起输入框
- **左键点击搜索按钮（放大镜图标）：** 展开输入框，可以输入文字提问

### 3.4 拖拽移动

- 用左键按住悬浮球不放，拖动到屏幕任意位置
- 松开鼠标后，悬浮球会自动吸附到最近的屏幕边缘
- 拖拽过程中菜单会自动隐藏

### 3.5 右键点击

- 右键点击悬浮球会弹出菜单窗口（与鼠标悬停效果相同）

## 四、输入框与提问

### 4.1 展开输入框

点击悬浮球右侧的搜索按钮（放大镜图标），输入框会向右展开。展开后自动聚焦输入框，可以直接打字。

### 4.2 输入文字提问

在输入框中输入问题文字，然后：

- **按 Enter 键：** 发送消息
- **按 Shift + Enter 键：** 换行（输入多行内容）
- **按 Esc 键：** 收起输入框
- **点击右侧发送按钮（箭头图标）：** 发送消息

发送后，会弹出聊天窗口显示对话内容。

### 4.3 截图提问

AIDI 支持截取屏幕画面后直接提问，AI 会根据截图内容回答。

**触发方式：**
- **快捷键 `Cmd + E`（macOS）** 或 **`Ctrl + E`（Windows）**：截取整个主显示器画面
- 截图完成后，输入框会自动展开，截图以缩略图形式显示在输入框上方

**截图操作：**
- 可以连续截多张图（最多 9 张），每次按快捷键截一张
- 点击缩略图可以查看大图
- 点击缩略图右上角的"×"按钮可以移除该截图
- 截图和文字可以混合发送（先截图，再输入文字描述问题）

> **macOS 首次使用截图：** 系统会提示需要授予"屏幕录制"权限。请前往"系统设置 → 隐私与安全性 → 屏幕录制"，勾选 AIDI Desktop，然后重启应用。如果未授权，输入框会显示"需要屏幕录制权限才能截图"的提示，点击该提示可直接跳转到系统设置面板。

### 4.4 IT 数据库检索

输入框右侧有一个"IT数据库"按钮：

- **默认关闭（灰色）：** AI 使用自身知识回答问题
- **开启后（高亮）：** AI 会额外检索公司 IT 知识库，回答更准确
- 点击该按钮即可切换开关状态

> **建议：** 提问公司内部 IT 相关问题时（如 OA 流程、软件安装、打印机连接等），开启 IT 数据库可获得更准确的回答。

### 4.5 停止发送

消息发送过程中，发送按钮会变为停止按钮（方块图标）。点击停止按钮可以中断 AI 的回答。

## 五、聊天窗口

### 5.1 打开聊天窗口

发送消息后，聊天窗口会自动弹出并显示在悬浮球旁边。聊天窗口是一个圆角矩形气泡，顶部有一个小尖头指向悬浮球。

### 5.2 聊天窗口功能

| 功能 | 操作方式 |
|------|----------|
| 新对话 | 点击左上角"新对话"按钮，结束当前对话，开始全新会话 |
| 重新回答 | 在最新一条用户消息上，点击右侧的圆形重试按钮（旋转箭头图标），让 AI 重新回答 |
| 查看历史 | 重新打开应用或切换模型后，会自动加载之前的对话历史 |
| 滚动查看 | 在消息列表中上下滚动查看所有对话内容 |

### 5.3 AI 回复中的卡片

AI 回复消息时，除了普通文字，还可能展示以下类型的卡片：

| 卡片类型 | 说明 |
|----------|------|
|卡片（🔗） | 显示相关 OA 流程链接，点击可直接跳转到对应 OA 页面 |
| 工具调用卡片（🔧） | 显示 AI 调用的工具名称、运行状态（运行中/完成/失败）和结果 |
| 代码卡片 | 显示代码块，支持语法高亮 |
| 表格卡片 | 以表格形式展示结构化数据 |
| 图片卡片 | 显示 AI 返回的图片内容 |
| 文件卡片 | 显示文件信息（PDF、Excel 等） |
| 思考卡片 | 展示 AI 的推理思考过程 |
| 快速回复卡片 | 提供 AI 建议的后续问题，点击可直接发送 |

### 5.4 模型切换提示

如果您在对话中途切换了 AI 模型（通过菜单窗口的"模型选择"），会弹出提示框：

> "已切换至「模型名称」，当前对话已结束，下一条消息将使用新模型开启新对话。"

点击"我知道了"关闭提示。下一条消息将使用新模型开始全新对话。

## 六、菜单窗口详解

### 6.1 界面外观

将鼠标移到"界面外观"上，右侧会展开子菜单，包含三组设置：

**主题模式：**
- 浅色：明亮主题
- 深色：暗黑主题
- 跟随系统：自动跟随操作系统的明暗设置

**透明度：**
- 拖动滑块调整悬浮球的透明度（30% ~ 100%）
- 透明度越低，悬浮球越透明，适合不遮挡桌面内容时使用

**颜色主题：**
- 提供多种颜色主题可选（如青紫、蓝绿等）
- 点击颜色圆圈选择，选中项会有高亮边框

### 6.2 模型选择

将鼠标移到"模型选择"上，右侧展开模型列表：

| 模型 | 说明 |
|------|------|
| 通义千问 | 同规模业界 SOTA 水平，默认模型 |
| DeepSeek | 混合推理架构模型 |

点击模型名称即可切换。当前选中的模型会有勾选标记。

### 6.3 系统优化

点击"系统优化"会打开系统优化工具窗口。该功能用于优化电脑性能，具体优化项以窗口内展示为准。

### 6.4 关于

将鼠标移到"关于"上，右侧展开子菜单，显示：

- **当前版本号：** 如 `v1.0.0`
- **检查更新按钮：** 点击后联网检查是否有新版本
- **更新详情：** 如果发现新版本，会显示新版本号、更新说明和"下载并安装"按钮
- **下载安装：** 点击后自动下载安装包，下载完成后自动安装

## 八、IT 运维场景

AIDI 内置 17 个 IT 运维场景。当您的提问关键词命中某个场景时，AI 会自动注入该场景的专属规则，给出精准的流程指引和 OA 链接卡片。

### 17 个场景一览

| 序号 | 场景 | 常见触发关键词 |
|------|------|----------------|
| 1 | 电脑借领用 | 借电脑、领电脑、借用电脑 |
| 2 | 资产委外维修 | 电脑维修、修电脑、设备维修 |
| 3 | 资产调拨 | 电脑调拨、资产调拨、调拨流程 |
| 4 | 资产交接 | 电脑交接、工作交接、离职交接 |
| 5 | 资产退库 | 电脑退库、归还电脑、离职退库 |
| 6 | 资产报废 | 电脑报废、设备报废、报废申请 |
| 7 | 资产查询 | 个人资产、名下资产、易点易动 |
| 8 | 设备申报 | 设备申报、设备审批、飞书无法登录 |
| 9 | WiFi 连接 | 免费 WiFi、访客网、公司 WiFi 密码 |
| 10 | 权限申请 | 权限申请、VPN、USB 权限、网盘权限 |
| 11 | 工业云账号 | 工业云申请、工业云注册 |
| 12 | 工业云使用 | 工业云登录、CAD 卡顿、NX 报错 |
| 13 | 软件安装 | 装微信、装 WPS、软件下载、白名单 |
| 14 | 授权软件安装 | 安装 NX、安装 CAD、安装 Photoshop |
| 15 | 打印机连接 | 连接打印机、打印机驱动、刷卡打印 |
| 16 | 默认打印机 | 设置默认打印机、切换默认打印机 |
| 17 | 性能诊断 | 电脑卡顿、电脑慢、性能报告 |

### 场景触发示例

**示例 1：问借电脑流程**
1. 点击搜索按钮展开输入框
2. 输入"我想借一台电脑"
3. 按 Enter 发送
4. AI 回复中会包含借领用流程说明，并附带"IS-37 电脑借领用申请"链接卡片，点击即可跳转 OA

**示例 2：问打印机怎么连**
1. 展开输入框，输入"理光打印机怎么连接"
2. 发送后，AI 回复连接步骤，并附带"理光打印机如何连接"链接卡片

**示例 3：截图提问电脑报错**
1. 按 `Cmd + E` 截取电脑上的报错画面
2. 截图缩略图出现在输入框中
3. 输入"这个报错怎么解决"
4. 发送后，AI 根据截图内容分析并给出解决方案

**示例 4：电脑卡顿诊断**
1. 输入"电脑很卡怎么办"
2. 命中性能诊断场景，AI 会自动运行本地硬件诊断命令
3. 回复中包含工具调用卡片（显示诊断运行状态）和详细的硬件性能报告

## 九、日常使用技巧

### 9.1 快速提问流程

1. 鼠标移到悬浮球上（或直接点击搜索按钮）
2. 输入框展开，输入问题
3. 如果是 IT 相关问题，开启"IT数据库"按钮
4. 按 Enter 发送
5. 聊天窗口弹出，查看 AI 回复
6. 如果回复中有链接卡片，点击直接跳转 OA

### 9.2 截图提问流程

1. 遇到电脑上的问题（报错弹窗、软件异常等）
2. 按 `Cmd + E` 截图
3. 输入框自动展开，缩略图显示
4. 输入补充说明文字（可选）
5. 按 Enter 发送

### 9.3 切换模型

1. 鼠标移到悬浮球上弹出菜单
2. 移到"模型选择"
3. 点击目标模型
4. 如果当前有对话，会提示"当前对话已结束，下一条消息使用新模型"

### 9.4 调整外观

1. 鼠标移到悬浮球上弹出菜单
2. 移到"界面外观"
3. 选择主题模式（浅色/深色/跟随系统）
4. 调整透明度滑块
5. 选择喜欢的颜色主题

### 9.5 开始新对话

1. 在聊天窗口中点击左上角"新对话"按钮
2. 之前的对话结束，可以开始全新的提问

## 十、常见问题

### Q1：悬浮球不见了怎么办？

- **方法一：** 检查系统托盘图标，右键选择"显示浮动球"
- **方法二：** 按快捷键 `Cmd + D`（macOS）或 `Ctrl + D`（Windows）切换显示
- **方法三：** 双击应用图标重新启动，会自动显示悬浮球

### Q2：截图没反应怎么办？

**macOS：** 需要授予屏幕录制权限。前往"系统设置 → 隐私与安全性 → 屏幕录制"，勾选 AIDI Desktop，然后重启应用。

**Windows：** 首次使用可能需要确认截图权限弹窗。

### Q3：AI 回答不准确怎么办？

- 开启"IT数据库"按钮，让 AI 检索公司知识库
- 尝试切换模型（通义千问 ↔ DeepSeek）
- 提供更详细的问题描述或截图

### Q4：如何退出应用？

右键系统托盘的 AIDI 图标，选择"退出"。

### Q5：如何更新到最新版本？

1. 鼠标移到悬浮球上弹出菜单
2. 移到"关于"
3. 点击"检查更新"
4. 如果有新版本，点击"下载并安装"

### Q6：输入框文字太多看不全怎么办？

输入框会自动根据内容调整高度。如果内容很多，输入框会出现滚动条，可以上下滚动查看。

### Q7：怎么同时发多张截图？

连续按 `Cmd + E`（或 `Ctrl + E`）多次，每次截取一张。最多支持 9 张截图同时发送。缩略图上会显示编号。

### Q8：发送的消息能撤回吗？

消息发送后无法撤回，但可以点击重试按钮让 AI 重新回答。点击"新对话"可以开始全新会话。
